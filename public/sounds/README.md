# Sound

`rift.wav` plays on each fast swipe.

It is "Conjunctioning squeal item" (#3147) from [Mixkit](https://mixkit.co/free-sound-effects/), with the silence trimmed from both ends. It is used under the [Mixkit Sound Effects Free License](https://mixkit.co/license/), not the MIT license that covers the code.

To use a different sound, replace `rift.wav` with any short whoosh or hit (wav, mp3 or ogg), or pass another URL as the `sound` option. Silence at the start and end is trimmed automatically when it loads. Without a sound file the rift works silently, and the demo hides its sound button.
